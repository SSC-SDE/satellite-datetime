# Security

This library does not implement cryptography. Issues that can cause incorrect
time conversion in dependent software should still be reported privately when
they are not already documented as 0.1 limitations (TCL approximation, tz
subset, TDB model).

Please use [GitHub security advisories](https://github.com/SSC-SDE/satellite-datetime/security/advisories/new)
on this repository. Do not file a public issue for a newly discovered conversion
bug that could affect navigation until we have a patched release.
